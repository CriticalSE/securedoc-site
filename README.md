# SecureDoc Site

Officiell publik webbplats för SecureDoc med sidor avsedda för GitHub Pages och App Store Connect.

## Sidor
- `index.html` – Marketing URL / startsida
- `support.html` – Support URL
- `privacy.html` – Privacy Policy URL
- `terms.html` – användarvillkor

## GitHub Pages
Publicera från branch `main` och root `/`.

Om repot heter `securedoc-site` blir adresserna normalt:
- `https://criticalse.github.io/securedoc-site/`
- `https://criticalse.github.io/securedoc-site/support.html`
- `https://criticalse.github.io/securedoc-site/privacy.html`
